# Poster and campaign adaptation

Design a composition, not a screenshot of a website. Retain the ink palette, lettering treatment, motif drawing style, and frame logic; change placement for the medium.

## Build the reading order

1. **Workshop name:** huge enough to read as a thumbnail, with deliberate word breaks and layered ink.
2. **Why attend:** one short, concrete line. For this workshop, a draft such as "Bring an idea. Give it a frontend." fits; treat it as editable campaign copy, not an event fact.
3. **Date / time / venue / how to join:** one clean ticket-like information band. Ask for these facts before a final promotional export; use clearly marked placeholders only in a draft.
4. **Organizer and hosts:** OpenAI Student Collective; Samarth Ryan Edward and Parv Bhawsar. Match hosts' typographic weight and size.

The bundled specimen uses known names but intentionally omits the event logistics. It is a visual study, not a ready-to-publish announcement.

## Layout variants

- **Portrait poster / social feed:** a tall framed title block, a hanging illustration interrupting one edge, then a readable footer ticket. Don't require a viewer to zoom into the names.
- **Story:** more top/bottom breathing room for platform UI, fewer tiny labels, and only one essential action.
- **Landscape banner:** set the title beside the illustration; use border rails above and below, not a dense complete frame if that shrinks the message.
- **Printed sheet:** use a deliberate trim-safe inner frame. Ask the printer for trim, bleed, color profile, and export specifications; web colors alone do not guarantee a matching print.

In HTML/SVG authoring, use rem for CSS dimensions. Vector path coordinates remain dimensionless. Physical print specifications may require millimetres or points: keep those as explicit export metadata rather than faking physical measurements with a rem conversion.

## Image and lettering craft

Work with vector lettering/text and motifs as long as possible. Keep small information live and legible. If converting display lettering to outlines for a final printer file, retain an editable text version and separately accessible event copy.

Choose either clean flat inks with subtle dots, or a more tactile collage with restrained wear. Don't stack all effects indiscriminately. Use hard shadow shapes rather than blurry compositing. Preserve intentional edges; don't pass the entire design through a faux distressed filter.

Typography should communicate the actual language. A mixed Latin/Devanagari composition is appropriate when its words are correct and useful. For a Tamil-speaking campus audience, ask whether Tamil copy is wanted instead of assuming Devanagari is the default Indian script. Don't animate or clip marks independently.

No generated text baked into an image when editable type works. Don't lift the celebrity portrait, existing slogans, logos, or watermarked art from the reference images into the workshop poster. Build original ornaments or use cleared assets.

## Export check

Check the final size, thumbnail readability, names, logistics, overflow, contrast, and any QR destination. A QR needs its proper clear margin and no halftone overlay. Don't fabricate a QR or registration link. Supply the editable source alongside the requested export. Print the specimen from a browser only as a design study: its print stylesheet is not a certified press-ready PDF workflow.
