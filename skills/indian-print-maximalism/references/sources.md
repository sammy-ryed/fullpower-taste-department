## Research that shaped the direction

- [NID: Latin Typeface Inspired from Indian Hand Painted Signs — Tathagata Biswas](https://youngdesigners.nid.edu/archive/yd22/project.php?q=2088). The project's account of layered lettering informed the face/keyline/extrusion treatment. No project artwork or font is bundled.
- [Yatra One's project description](https://github.com/google/fonts/blob/main/ofl/yatraone/DESCRIPTION.en_us.html). This display face draws on Mumbai railway signage; it is a specific type-design reference, not a universal Indian font.
- [GSAP matchMedia](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/). Consulted for optional component-scoped animation and responsive/reduced-motion cleanup. No GSAP library is bundled.
- [Tailwind theme variables](https://tailwindcss.com/docs/theme#referencing-other-variables). The inline theme declaration keeps semantic shadow references evaluated where the utility is used.

The particular palette, layouts, motif drawings, and motion recipes in this skill are design choices, not claims about how the reference sites are implemented.

## Package use

The `.zip` and `.skill` downloads contain the same single-folder skill bundle. The latter is a ZIP archive with a `.skill` extension, not a different binary format. A host must support that import convention; otherwise extract the ZIP and provide the folder or its `SKILL.md` with the linked resources. No global installation or remote publication is performed by this bundle.
